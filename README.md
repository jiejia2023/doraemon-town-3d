# 哆啦A梦 · 大雄的小镇 — 月见台町 3D

用 **Three.js** 还原藤子·F·不二雄《哆啦A梦》中大雄居住的小镇的粉丝同人网页，可直接在浏览器中漫游。

🌐 **在线访问（GitHub Pages）**： https://jiejia2023.github.io/doraemon-town-3d/

![Doraemon](https://img.shields.io/badge/Three.js-0.160-0096e6) ![Fan Made](https://img.shields.io/badge/Fan--made-Tribute-ff6fa5)

小镇原型一般认为在东京练马区一带，哆啦A梦、野比大雄、源静香、刚田武（胖虎）、骨川小夫等角色以低多边形小人形式出现在各自的经典位置，哆啦A梦头上还有旋转的竹蜻蜓。

## 功能

- 🖱️ 拖拽旋转 / 滚轮缩放 / 右键平移，点击建筑弹出介绍
- 📍 左侧地标导航，一键飞镜前往
- ▶ 自动巡游模式
- 🌙 日夜切换：夜晚路灯亮起、各家窗户透出暖光
- 🌸 樱花花瓣飘落、喷泉水滴、流动的云、河面微光、行驶的汽车与电车
- 🏷️ 地标标签开关

## 本地运行

```bash
# 任意静态服务器即可（需要通过 http 打开以加载 ES Module）
npx serve .
# 或
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术

- Three.js 0.160（CDN Import Map，无需构建）
- 全部建筑/角色均为代码程序化建模（无外部模型文件）
- GitHub Actions 自动部署 GitHub Pages
